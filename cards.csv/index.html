cards.csv Guide

cards.csv is a CSV file that helps you add more features to your brawler for brawler screen.

Name: The name of the card.

Card name types 
X_unlock = Brawler card
X_hp = HP
X_abi = Attack skill type
X_ulti = Super skill type
X_unique = Star power
X_gadget or X_customname = Gadget

IconSWF: File path of the icon for the card.

IconExportName: Icon export name from the SC file that written at IconSWF for the card icon.

Target: Brawler CodeName which is attached to characters.csv. You have to write the brawlers CodeName there to specify the card for the brawler.

LockedForChronos: If you set it as "true", the card will be disabled and won't be shown on brawler screen.

DynamicRarityStartSeason: If you set a season number for this column, brawlers rarity will be changed to chromatic.

MetaType: The type of the card.

All MetaTypes: 
0 = unlock
1 = hp
2 = weapon skill
3 = ulti skill
4 = star powers
5 = accessory(gadgets)

RequiresCard: Unused, but I think if you put another cards name there, you will need that card to unlock the card.

Type: Type of the card. All types are unlock, hp, skill(weapon and ulti) and accessory. Star powers are hardcoded and have their own custom types.

Skill: Skill name if the type is skill.

Value, Value2 and Value3: Value for the skills, star powers and gadgets.

Rarity: Rarity of the brawler.

TID: Text ID for the card.

PowerNumberTID, PowerNumber2TID and PowerNumber3TID:

PowerIcon1ExportName and PowerIcon2ExportName:

SortOrder: It is for ordering the brawlers. If the number is lower, the brawler will be shown earlier in the brawler tab.

DontUpgradeAStat: If you don't want this card to gain an upgrade, set this as "true".

HideDamageStat: If you want to hide the damage stats of the brawler(which is in the brawler attack and ulti descs), set this as "true".
