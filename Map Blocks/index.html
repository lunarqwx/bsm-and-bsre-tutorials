Map Blocks

Map blocks are a small portion of the map which you can use to build a full sized map using multiple different parts, or even randomize them by giving different parts the same name.

Each map block is structured to be 8x8. Multiple blocks can have the same name and the game will choose a random one during the game. As for the map preview, the game will choose the first block that comes up for the preview (in the order that it's placed inside map_blocks.csv)

You can check map_blocks.csv for further reference on its structure.

Map Structure

Inside maps.csv, you can find GeneratedRobo which serves as a great reference in order to create your very own randomized map.

You can use as many blocks you want in order to create your map, you just have to use 0 as spacing.

WARNING: You MUST use 0 in spacing (example: blockfirst,0,blocklast,0) OTHERWISE your map wont work and your game will freeze.

CodeName

Unlike CodeName in maps.csv which uses plain numbers to index the map data, map blocks use both letters and numbers to index (r0, r1) etc.

If your Data isn't indexed, the game will simply not read that part of the map and you'll be left with a corrupted block/map.

Map data. Each Row contains a layer of the map. You can have a maximum of 8 tiles and 8 layers, any more and the game refuses to load. this is frustrating if you want to do showdown maps because you have to use a lot more pieces which can get hard to do.
