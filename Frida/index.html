Frida Guide

What is Frida?

Frida is for adding custom stuff with coding other than using CSV, SC and other files. You can add custom mechanics, custom buttons, Brawl Pass, shop and more.

How To Attach Frida Scripts?

Requirements:

- Apktool M

- Mt manager(optional)

1. Go download Frida Releases.

I think the version doesn't really matter, but I heard that 16.0.0 is better.

You can rename it to anything you want, for an example "libbunny.so". But keep lib at the beginning.

2. Decompile your apk using Apktool M, with classes.dex.

Go to: 
smali/com/supercell/titan/GameApp.smali

3. Search "g" (include the "). You should see see "cat" text 3 lines later. At bottom of the cat add:

     invoke-static {v0}, Ljava/lang/System;->loadLibrary(Ljava/lang/String;)V 
     
     const-string v0, "XXX"

XXX will be your libscript name, for example if you used bunny then name it "bunny".

After these put your libbunny.so (Frida Gagdet) in lib folder.

4. Now create a file named "libXXX.config.so"(for an example, libbunny.config.so). Put this in that file:

     {
         "interaction": {
             "type":"script",
             "path":"libXXX.script.so",
             "on_change":"reload"
         }
     }

libXXX.script.so will be "libbunny.script.so" for an example.

5. Take the libscript.script.js file (the Frida script itself). Rename it like you did before, for me it's libbunny.script.so add `.so` at the end, not `.js`.

If you want to add a script to your Brawl Stars Mod you have to create your own Frida scripts or get free & public ones from Supercell World Discord Server.

6. After these compile ur project and download the APK, it should work. Now you have your scripted Brawl Stars Mod!
