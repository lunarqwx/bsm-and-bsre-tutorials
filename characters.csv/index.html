LockedForChronos: Unlike disabled, this allows the brawler to be enabled after the serverside timer ends.

Disabled: If it setted as "true", the brawler won't be shown in the brawler tab.

ItemName: The brawlers name are used in this column. You have to use frida to make your custom brawlers work in there. Otherwise it will crash. But you can use an existing brawlers name.

WeaponSkill: Brawlers attack which is attached to skills.csv.

UltimateSkill: Brawlers super which is attached to skills.csv.

Pet: Brawlers pet.

Speed: Characters speed.

Hitpoints: Characters HP.

Heres a formula for HP and Damage points depends on the level, made by Gabriel and Mortibi.

maxHitpoints: int = int(input("Maximum Hitpoints: "))
maxDamage: int = int(input("Maximum Damage: "))
heroLevel: int = int(input("Brawler Level: "))

baseHealth = int(maxHitpoints / (1 + (heroLevel - 1) / 20))
baseDamage = int(maxDamage / (1 + (heroLevel - 1) / 20))

print(f"Base hitpoints at level 1: {baseHealth}")
print(f"Base damage at level 1: {baseDamage}")

MeleeAutoAttackSplashDamage: Isn't used.

AutoAttackSpeedMs: NPC or pet's attacks speed as milliesecond.

AutoAttackDamage: NPC or pet's attacks damage.

AutoAttackBulletsPerShot: Number of bullets per shot for NPC(bots) or pets.

AutoAttackMode: I have no idea.

AutoAttackProjectileSpread: The spread of the attack for NPC and pets.

AutoAttackProjectile: The name of the projectile for NPC and pets.

AutoAttackRange: The range of the attack.

RegeneratePerSecond: I don't know.

UltiChargeMul and UltiChargeUltiMul: They are for calculating the super charge when the brawler attacks to the enemy. Here's a formula for them made by Gabriel:

baseDamage: int = int(input("Base Damage: "))
chargeMult: int = int(input("Charge Multiplier: "))

chargeFromHit : int = int(chargeMult * (baseDamage / 100))
print(f"Charge Obtained from an hit: {chargeFromHit}")

totalCharge: int = chargeFromHit
nHits: int = 1
while totalCharge < 4000:
    totalCharge = totalCharge + chargeFromHit
    nHits = nHits + 1

print(f"Got ulti in {nHits} hits!")

Type: The type of the character.

Character types list 
Hero = Brawler
Minion_Building = Like map blocks but killable. For an example TNT Box.
Minion_Building_charges_ulti = Same as Minion_Building but that charges super.
Pvp_Base = Minion_Building but has an important role for the game event. For an example Safe is Pvp_Base because destroying it is the goal for Heist.
Minion_FindEnemies = Pets that can walk and find enemies. For an example Nita's bear is Minion_FindEnemies.
Minion_Dog = Unused and for BoneThrower(unused brawler).
LaserBall = Ball for the Brawl Ball.
LootBox = Box that has power cubes.
Minion_FollowOwner = Pet that follows the owner brawler.
Npc_Boss = Boss Bot for the game event.
Minion_FindEnemies2 = Same as Minion_FindEnemies but for bots.
RoboWars = For Robo Wars.
Train = Trains that gives damage to the player in gem grab.
CaptureFlag = For Capture Flag game mode.
Minion_Mirage = A pet that is an illusion. Used for Leon's gadget.
Npc_Boss_TownCrush = For Kaiju, boss that destroys the environment.

DamagePercentFromAliens: If that value is 0<X, the character will resist the damage for X% for NPCs.

DefaultSkin: Characters main and default model other than their skins.

FileName: Used for TNT box.

BlueExportName: Blue color of the TNT box.

RedExportName: Red color of the TNT box.

ShadowExportName: Shadow of the TNT box.

AreaEffect: Area Effect for the character, which is an effect that around the character; gives stun, damage, slow, speed etc. It is attached to area_effects.csv.

DeathAreaEffect: Area effect that triggers when the character dies. Attached to area_effects.csv.

TakeDamageEffect: A visual effect that triggers when you take damage, which is attached to effects.csv.

DeathEffect: A visual effect that triggers when you die, which is attached to effects.csv.

MoveEffect: Visual effect when you move, which is attached to effects.csv.

ReloadEffect: Visual effect when you reload your ammo, which is attached to effects.csv.

OutOfAmmoEffect: Visual effect when you are out of ammo, which is attached to effects.csv.

DryFireEffect Visual effect when you are trying to attack while you are out of ammo, which is attached to effects.csv.

SpawnEffect: A visual effect that triggers when the character spawns, which is attached to effects.csv.

MeleeHitEffect: Melee attack effect, which is attached to effects.csv.

AutoAttackStartEffect: Auto attack effect/MainAtkEffect for pets who use auto attack rather than skills. Attached to effects.csv.

BoneEffect1, 2, 3 and 4: Effects that are attached to a parent bone. Attached to effects.csv.

LoopedEffect and LoopedEffect2: Visual effects that loops constantly for ingame. Attached to effects.csv.

KillCelebrationSoundVO: Voicelines that occurs when you kill someone. Attached to sounds.csv.

InLeadCelebrationSoundVO: Voicelines that occurs when you are on the lead. Attached to sounds.csv.

StartSoundVO: Voicelines that occurs when the game starts. Attached to sounds.csv.

UseUltiSoundVO: Voicelines that occurs when you use your super/ulti. Attached to sounds.csv.

TakeDamageSoundVO: Voicelines that occurs when you take damage from the enemy. Attached to sounds.csv.

DeathSoundVO: Voicelines that occurs when you die. Attached to sounds.csv.

AttackSoundVO: Voicelines that occurs while attacking. Attached to sounds.csv.

AttackStartEffectOffset:

TwoWeaponAttackEffectOffset: This column controls the distance between projectiles in skills who use TwoGuns.

ShadowScaleX: Character scale horizontally.

ShadowScaleY: Character scale verically.

ShadowX and ShadowY: You put 0 to make a character not have a shadow.

ShadowSkew: I have no idea.

Scale: Battle scale.

HeroScreenScale: Scale of the brawler for the brawler menu.

FitToBoxScale: Scale of the brawler for shop offers(?).

EndScreenScale: Scale of the brawler for battle end scale.

GatchaScreenScale: Scale of the brawler for boxes.

HomeScreenScale: Scale of the brawler for home screen.

ShowPetInHeroScreen: If you set that as "true", the pet of the brawler will be shown in the menu.

HeroScreenXOffset: Brawler menu offset Left/Right.

HeroScreenZOffset: Brawler menu offset Front/Back.

HeroScreenEmoteX: Emote button offset left/right.

HeroScreenEmoteY: Emote button offset up/down.

CollisionRadius: Hitbox size for the brawler.

HealthBar: Health bar type for the character, which is attached to health_bars.csv.

HealthBarOffsetY: Health bars up/down offset.

FlyingHeight: Unused.

ProjectileStartZ: Where from the brawler hitbox the projectiles start.

StopMovementAfterMS: Unused.

WaitMS: Unused.

TID: Text ID for the character.

ForceAttackAnimationToEnd: Unused.

IconSWF: File location for the brawlers portrait/icon.

IconExportName: The name of the icon in SC files.

RecoilAmount: How much the character moves after an attack, usually paired with RecoilAnimation.

Homeworld: Unused.

FootstepClip: It's hardcoded, but without it the characters do not have a footstep. Rhinostep is for charges/dashes and set in skills.csv.

DifferentFootstepOffset: Z offset for how far away it appears beyond the character.

FootstepIntervalMS: How frequently the footsteps are spawned.

AttackingWeaponScale: The scale of the weapon & attack.

UseThrowingLeftWeaponBoneScaling: Scales weapon when throwing, but for left side.

UseThrowingRightWeaponBoneScaling: Scales weapon when throwing, but for right side.

CommonSetUpgradeBonus: Legacy upgrade system column, for common rarity.

RareSetUpgradeBonus: Legacy upgrade system column, for rare rarity.

SuperRareSetUpgradeBonus: Legacy upgrade system column, for super rare rarity.

CanWalkOverWater: This column was for making the character move over water, but it doesn't work anymore unless if you fix it with Frida.

UseColorMod: You can alter the color of the characters texture with this column. The game gets the original valued per pixel itself.

The Formula of UseColorMod: 
R'/G'/B' = (R/G/B * Mul) + Add

ChargeUltiAutomatically: Automatic ulti charge rate. If its higher you charge your super automatically faster.

VideoLink: Unused.

ShouldEncodePetStatus: Usually for hardcoded stuff. In Tick and RT's case, it encodes the pet status to use it for purposes such as turning pieces of the model invisible.

SecondaryPet: Checks if this character is another characters pet.

ExtraMinions: How many pets this character can have in one battle at max.

PetAutoSpawnDelay: Sets how frequently the character's pet respawns after dying.

HasPowerLevels: If it setted as "true", the brawler will have the same mechanic as surge, who gets an upgrade every super.

OffenseRating, DefenseRating and UtilityRating: The rating on brawler screen, they can be setted as 5 max.
